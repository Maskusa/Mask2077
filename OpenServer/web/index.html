WireGuard — локальный тест

Выберите страницу для проверки:

  • Генерация QR из конфига (статическая)
  • Получить QR одной кнопкой (требуется PHP ssh2)
  • Веб-управление сервером (требуется PHP)
  • tcpdump (старт/стоп, просмотр лога)

Если PHP не установлен локально, используйте wg_qr.html или установите PHP и перезапустите через ./serve.ps1.
